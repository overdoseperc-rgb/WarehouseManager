# Учёт остатков товаров на складе

Работа по файлу «задание на хеш-таблицы.docx». C#, .NET 8.

## Запуск

1. Распакуйте архив.
2. Откройте WarehouseManager.sln в Visual Studio 2022 версии 17.8 или новее
   с установленной поддержкой .NET 8.
3. Нажмите Ctrl+F5.

## Работа с программой

- 1 — поиск товара по артикулу.
- 2 — приход: введите артикул и положительное количество единиц.
- 3 — продажа: введите артикул и количество. При нехватке продажа блокируется.
- 0 — выход.

Пример: найдите 1001 (остаток 50), добавьте 10 (остаток 60),
продайте 5 (остаток 55). Попытка продать 100 оставит остаток 55.

## Данные и код

products.csv — исходные товары из задания, UTF-8, без строки заголовков.
Каждая строка: Артикул;Название;Цена;НачальныйОстаток.
Для своей базы измените этот файл в проекте. При сборке он копируется рядом
с программой. В цене допустима точка или запятая. Артикулы должны быть уникальными.
В названии товара не используйте точку с запятой: формат CSV в задании простой.

Product.cs — класс товара со свойствами Article, Name, Price, Quantity.
Program.cs — главный Dictionary<string, Product>, загрузка CSV и консольное меню.
Поиск выполняется через TryGetValue. Приход и расход изменяют Quantity.
Ошибочный ввод количества можно повторить; неизвестный артикул возвращает в меню.

Изменения остатков хранятся в памяти во время работы программы.
После нового запуска загружаются начальные остатки из CSV.
